Here is the simple, student-friendly English version: 
`input()` is the computer listening to you—it takes whatever you type on the keyboard and saves it in memory as text (even if you type numbers), while `print()` is the computer talking—it displays those saved details or your own messages on the screen.
---
This program is a simple student ID card generator written in Python. It takes basic information from the user and turns it into a neat, easy-to-read student profile on the terminal screen.
First, the program uses the `input()` function to ask you five quick questions. It asks for your full name, student ID, major, favorite programming language, and target graduation year.
Second, every answer you type on the keyboard is temporarily stored in variables inside the computer's memory as text. This allows the program to remember your answers for the next step.
Third, the program uses `print()` functions to format all your answers into a clean card layout. It adds decorative borders made of equal signs (`=`) so the output looks like an organized digital card
Finally, this code shows how a basic program interacts with a user. It simply collects data from the keyboard and displays it back to you in a well-structured format.
